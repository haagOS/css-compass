# Benchmarks

Run with `pnpm bench` (`scripts/bench.ts`). Input is generated by `src/core/bench-input.ts`:
tokens in `:root` with `var()` chains and a `data:` URL, two theme classes, utility classes in
`@layer` (some with escaped names), components with nesting, `@media`, comments, strings and
`url()`. Each case runs a 300 ms warm-up, then at least 50 iterations. Budgets: SPEC §8.

## M1 — 2026-11-18

Windows 11, Node 24.18. Input: 10,005 lines, 291,836 chars (minified 231,365); 2,441 rules,
4,798 classes, 801 custom properties.

| Case | Median | p95 | Budget |
|---|---|---|---|
| scan 10k lines | 1.50 ms | 2.28 ms | ≤ 3 ms |
| scan 10k lines, minified | 1.26 ms | 1.52 ms | ≤ 3 ms |
| scan 10k lines as CSS Module | 1.47 ms | 1.60 ms | ≤ 3 ms |
| index: replace one 10k-line file | 1.28 ms | 2.96 ms | — |
| index: completion name lists (21 files) | 0.008 ms | 0.013 ms | — |
| index: find a property defined in 21 files | 0.001 ms | 0.001 ms | — |

The first run measured 16 ms per scan: escape detection searched to the end of the file for
every identifier (quadratic). Fixed before commit.
